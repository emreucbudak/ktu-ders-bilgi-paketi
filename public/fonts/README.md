# Geom font asset

- Family: Geom (variable weights 300–900), a Google Fonts geometric sans-serif.
- Google Fonts: https://fonts.google.com/specimen/Geom
- Upstream project: https://github.com/ThanosPoulakidas/Geom
- Source: Latin and Latin Extended WOFF2 subsets served by Google Fonts; the Latin Extended subset includes Turkish glyphs.
- License: SIL Open Font License 1.1. See `OFL.txt`.
- Geom is a geometric-sans alternative, not the proprietary Hurme Geometric Sans named in the KTÜ identity guide.
